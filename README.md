

مدیریت فعالیت‌های واحد نقشه
نسخهٔ وب سامانهٔ مدیریت فعالیت‌های واحد نقشه. برای استفاده، برنامه را از طریق GitHub Pages منتشر کنید.

اجرا و انتشار
فایل 
index.html
 نقطهٔ ورود اصلی GitHub Pages است.
فایل 
مدیریت_فعالیت_های_نقشه_پیشرفت.html
 نیز نسخهٔ هم‌محتوای برنامه است.
برای انتشار، فایل‌های تغییرکرده را در شاخهٔ main ذخیره (Commit) کنید. پس از انتشار، صفحه را با Ctrl+F5 یا تازه‌سازی کامل بارگذاری کنید.
امکانات
مدیریت فعالیت‌ها، وضعیت و میزان پیشرفت
داشبورد و گانت‌چارت
دفترچهٔ نکات اصلاح و ارتقا
مدیریت نقشه‌های پیشرفت بر اساس شهرستان، فصل و فعالیت
ورود و خروجی داده‌ها با فایل‌های JSON و Excel
ذخیره‌سازی و همگام‌سازی داده‌ها
برنامه از حافظهٔ مرورگر (localStorage) برای نگهداری داده‌ها استفاده می‌کند و برای همگام‌سازی ابری نیز به Supabase متصل شده است. تغییرات بخش نقشه‌های پیشرفت نیز باید به ذخیره‌سازی ابری ارسال شوند.

برای اینکه داده‌ها میان کاربران یا دستگاه‌های مختلف مشترک باشند، ورود به سامانه باید موفق باشد و پروژهٔ Supabase باید جدول app_state و مجوزهای لازم برای خواندن و به‌روزرسانی آن را داشته باشد. اگر اتصال ابری یا مجوزها درست تنظیم نشده باشند، ممکن است اطلاعات فقط در همان مرورگر باقی بمانند. پس از ثبت تغییرات مهم، از بخش داده‌ها نسخهٔ پشتیبان JSON یا Excel بگیرید.

نکتهٔ امنیتی
اطلاعات ورود کاربران را در این مخزن یا در README قرار ندهید. دسترسی به داده‌ها باید با تنظیم درست مجوزهای Supabase کنترل شود.
