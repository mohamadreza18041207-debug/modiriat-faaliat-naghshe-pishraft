# سامانه مدیریت نقشه پیشرفت

این مخزن شامل نسخه‌ی آنلاین سامانه مدیریت نقشه پیشرفت است.

## اجرا

فایل `مدیریت_فعالیت_های_نقشه_پیشرفت.html` را در مرورگر باز کنید یا آن را با GitHub Pages منتشر کنید.

## نکته درباره داده‌ها

نسخه‌ی فعلی اطلاعات را در `localStorage` مرورگر ذخیره می‌کند. بنابراین کد برنامه بین همکاران مشترک می‌شود، اما داده‌های ثبت‌شده در هر مرورگر جداگانه باقی می‌ماند. برای اینکه تغییرات هر همکار برای همه نمایش داده شود، باید ذخیره‌سازی به یک پایگاه‌داده‌ی آنلاین و احراز هویت کاربران متصل شود.
